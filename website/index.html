ABOUT SKILLGAP AI

Turn “What should I learn?” into a clear next step.

Choosing a career path is easier when you can see where you are today. SkillGap AI brings a student's profile, skills and career goals together in one place.

It compares current proficiency with the requirements for a selected role, calculates a weighted readiness score and highlights the skills to focus on next. The Salesforce project also includes a dashboard, career suggestions, learning resources and a way to save an analysis.

WHAT YOU CAN DO

Everything you need to find your focus.

A connected set of tools for understanding skills, measuring readiness and planning the next move.

01

Student profiles

Keep student details and target career roles together in a dedicated profile.

02

Skill inventory

Track each student's skills alongside their current and target proficiency levels.

03

Role requirements

Define the skills a job role needs, including required levels and optional weights.

04

Skill gap analysis

Compare a student's skills with role requirements and surface the levels still to develop.

05

Readiness score

Calculate a weighted percentage that summarizes progress toward the selected role.

06

Learning next steps

See skill priorities, curated learning resources and existing student learning tasks.

07

Progress & saved reports

Review skill progress in the dashboard and save an analysis result with its readiness score and gap details.

HOW IT WORKS

A thoughtful path from skills to strategy.

Six straightforward steps connect student skills to a more confident career plan.

STEP 01

Create a profile

The student profile captures the student's details and target role.

STEP 02

Add current skills

Record skills and proficiency levels to build a starting point.

STEP 03

Choose a role

Select the career goal with its configured skill requirements.

STEP 04

Compare skills

The analysis matches current levels against required levels.

STEP 05

Calculate readiness

Apex computes an overall readiness percentage using skill weights.

STEP 06

Plan what’s next

Review gaps, priorities, learning resources and assigned tasks.

READINESS, MADE CLEAR

A score that shows where you stand.

In the Salesforce project, Apex compares each current skill level with its required level and combines the results using the configured weights. Try this small, independent illustration.
